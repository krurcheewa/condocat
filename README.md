# CondoCat – ระบบร้านค้าออนไลน์คอนโดแมว

PHP 8 + MySQL/MariaDB (XAMPP)

## ติดตั้ง
1. เปิด Apache และ MySQL ใน XAMPP Control Panel
2. Import ฐานข้อมูล: phpMyAdmin → Import → `database/condocat.sql`
   หรือรันคำสั่ง `C:\xampp\mysql\bin\mysql.exe -uroot < database\condocat.sql`
3. สร้างภาพสินค้าตัวอย่าง: `C:\xampp\php\php.exe database\seed_images.php`
4. หน้าร้าน: http://localhost/condocat/
   หลังร้าน: http://localhost/condocat/admin/

ตั้งค่าการเชื่อมต่อฐานข้อมูล ค่าส่ง และบัญชีธนาคารได้ที่ `config.php`

## บัญชีทดสอบ
| บทบาท | อีเมล | รหัสผ่าน |
|---|---|---|
| ผู้ดูแลระบบ | admin@condocat.local | admin123 |
| ลูกค้า | user@condocat.local | user123 |

## ฟีเจอร์
**หน้าร้าน**: แสดงสินค้า ค้นหา/กรองตามหมวดหมู่และขนาด, หน้าสินค้าเลือกขนาด (S/M/L/XL) ที่มีราคา ขนาดจริง จำนวนชั้น และสต็อกแยกกัน,
ตะกร้าสินค้า, สมัครสมาชิก/เข้าสู่ระบบ, สั่งซื้อ (โอนเงิน/เก็บเงินปลายทาง), แนบสลิป, ติดตามสถานะและเลขพัสดุ

**หลังร้าน**: แดชบอร์ดยอดขาย/ยอดขายตามขนาด/สินค้าใกล้หมด, จัดการสินค้าพร้อมราคาและสต็อกแต่ละขนาด, จัดการขนาดคอนโด,
หมวดหมู่, คำสั่งซื้อ (ตรวจสลิป เปลี่ยนสถานะ ใส่เลขพัสดุ คืนสต็อกเมื่อยกเลิก), รายชื่อลูกค้า

## โครงสร้างฐานข้อมูล
- `users` ผู้ใช้ (customer/admin)
- `categories` หมวดหมู่
- `sizes` ขนาดมาตรฐาน
- `products` สินค้า
- `product_variants` สินค้า × ขนาด (ราคา, สต็อก, ขนาดจริง, จำนวนชั้น)
- `orders`, `order_items` คำสั่งซื้อ
